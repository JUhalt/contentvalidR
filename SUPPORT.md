# Support

For package usage, begin with the README and the contentvalidR pkgdown
website.

For methodological questions about substantive validity, content
validity, interpretation, or the scope of a package method, use the
**Methodological question** issue form.

For reproducible software problems, use the **Bug report** form.

For proposed capabilities or improvements, use the **Feature request**
form.

Please do not use public issues for sensitive security reports; follow
`SECURITY.md` instead.
